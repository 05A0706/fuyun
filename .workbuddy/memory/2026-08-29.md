**踩坑与决策（重要）**
1. auxgov 从 memctl 抽离时漏了 `get_fg_pkg_cached` 与 `FG_CACHE*` 变量，造成调用悬空——**`sh -n` 只查语法，查不出未定义函数**，必须额外逐个核对「被调用函数是否都有定义」。已补。
2. **放宽安全约束**：原方案「每个 cluster 至少保留 1 个在线核」会让功能在目标机型上完全失效（8+ Gen1 / 8 Gen2 大核簇通常只有 cpu7 一颗，永远关不掉）。改为 **cpu0 永不 offline + 小核簇永不参与关核**（系统始终保有一整簇算力），此前提下大/中核允许整簇关闭（关核数上限 = 簇总数）。配套：`BIG_OFF`/`MID_OFF` 上限由 簇数-1 改 簇数；叠加层由「压到剩 1 颗」改为「关闭全部大核」，中核维持基线。
3. **叠加层跨进程共享**：auxgov（`--off idle`）与 corectl 自身息屏检测是两个独立触发源，叠加状态持久化到 `corectl.overlay` 文件（每行 idle/screen），apply 每次重读文件计算，避免两套进程各自轮询 dumpsys。
4. 息屏期间巡检收紧到 5s（沿用旧 freq_limit 思路），否则亮屏后「只跑小核」的卡顿可直接感知。
5. `status.sh` 解析 `corectl.sh status` 时用 **函数 + heredoc** 而非管道，否则 while-read 在子 shell 中跑，变量赋值全丢。

**验证**：全仓库 `sh -n` 通过、`node --check app.js` 通过；corectl 18 个函数 / auxgov 19 个函数逐个核对定义唯一；代码目录无 freq_limit/freq_range 残留（powercfg_once.sh 的 gpufreq 是 GPU 频率，勿动）。

## 第十轮：打包（新增 build.sh + 版本 bump）

- 打包机理解记：`install.sh` 走 `unzip -o "$ZIPFILE" -x 'META-INF/*' -d $MODPATH`；`customize.sh`(KSU) 走 `cp -af` 顶层项（跳过 META-INF 与自身）。所以 **zip 根必须直接是 module.prop 等模块内容，不能有外层目录**。META-INF 是旧版 Magisk module_installer.sh（3701B，完整），`updater-script` 内容为 `#MAGISK`，均无需改动。
